This repository contains the code for the manuscript: **Bidirectional Relationship and Shared Mechanisms Between Sarcopenia and Osteoporosis: An Observational Study Integrating Genomic, Proteomic and Metabolomic Data**.

## Code
All analysis code is available in the [`/code`](https://github.com/siqixu/sar-ost/tree/main/code) folder.

## Derived datasets
All derived datasets used in this study are provided via Google Drive: https://drive.google.com/drive/folders/1Yg8n_k4jFhNwQ6r4LqrWlJHcOk-mV0cx?usp=drive_link.
